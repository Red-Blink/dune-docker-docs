# Players and Guilds

The Players page combines identity, location, progression, inventories, vehicles, bases, blueprints, and administrative repair tools for each character.

## Player Views

- Character and account identity, online state, map/Sietch, and actual character level.
- Inventory, crafting/research/building unlocks, and specialization progress.
- Owned and shared vehicles.
- Owned and shared bases, using the same expandable details as the global Bases page.
- Administrative history and actions allowed by the current role.

## Repairs and Recovery

Targeted repair actions address known inconsistent game records without blindly resetting unrelated progression. These include faction/progression repairs, gear checks, Landsraad **Repair Quests**, and deleted-character recovery when recoverable database data still exists.

Character recovery restores a locally deleted character record; it is not a cross-server transfer rollback and does not recreate data that has already been purged by the game.

## Movement

An online character can be teleported live to coordinates, another online player, their own base, or a shared/selected base. Base teleport uses the Sub-Fief console position so the destination is anchored to the claim instead of guessing a floor height.

## Guilds

The Guilds page shows guild membership and relevant server-side guild configuration. Guild limits come from effective game settings; duplicated raw settings are normalized in the Console presentation.

See [Blueprints](https://github.com/Red-Blink/dune-awakening-selfhost-docker/blob/main/docs/console/blueprints.md) for import/export and repair details.
