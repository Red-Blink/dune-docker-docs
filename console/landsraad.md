# Landsraad

The Landsraad page presents the game's faction, house, objective, and milestone data available in the current server database.

## Quest Repair

If a player cannot accept a new Landsraad quest even though fewer than the normal number appear active, select the offline player and use **Repair Quests** from Player Admin. The repair detects orphaned or defunct quest-slot records and removes only the inconsistent assignment, allowing the game to allocate the slot again.

{% hint style="warning" %}
Quest repair is targeted at the known hidden-slot inconsistency. It cannot guarantee a fix for every future Funcom quest bug and does not complete quests or award rewards.
{% endhint %}
