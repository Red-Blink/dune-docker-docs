# Console Overview

The browser Console is organized into three groups.

| Group | Pages |
|---|---|
| Server Operations | Home, Server Control, Backups, Database, Updates, Logs, Settings |
| Arrakis Management | Maps, Players, Guilds, Bases, Vehicles, Exchange, Live Map, Landsraad, Admin Tools, Care Package |
| Community | Addons |

**Home** is the best starting point for current health, readiness, version information, server actions, and first-run status. Other pages focus on a single responsibility and show confirmations before disruptive or destructive actions.

The header's language icon opens [Languages and Translation Corrections](languages.md); it is separate from the sidebar pages. **Requests**, **Report Issues**, and **Get Help** open external project services and are marked with an external-link icon.

Before installing, [explore the Console with sample data](../community/console-preview.md).

## Important Behavior

- Buttons that change game data are audited and protected by the Console's authorization policy.
- Some game-data changes require a player to be offline; the relevant action tells you when this is required.
- Some map configuration changes require only Overland or affected map instances to restart. Read the confirmation text before applying.
- Actions that provide a safety backup label it clearly; this is not a substitute for making a current backup before a restore or unfamiliar maintenance.
- Long-running operations remain visible as tasks and report their final result.

{% hint style="info" %}
Prefer the guided Console for daily work. The CLI remains available for automation, recovery, and advanced troubleshooting.
{% endhint %}
