# Admin Tools and Care Packages

Admin Tools collects actions that operate on players, maps, inventory, progression, vehicles, and messages.

## Common Tools

- Search and grant catalog items, schematics, augments, variants, and swatch sets.
- Award XP, specialization progression, skill points, and supported unlocks.
- Teleport online players to coordinates, another player, or a base.
- Send a message to one map or broadcast server-wide.
- Schedule daily or weekly map messages in a chosen timezone.
- Configure restart warnings and other operational announcements.

## Care Packages

Care Packages bundle grants for manual delivery or automatic rules such as first seen. Delivery history is tied to the player's Funcom identity, not merely a character name, so deleting and recreating a character does not normally qualify the same account again.

Enabling an automatic rule also enables its parent Care Package so the rule cannot appear configured while delivery is globally disabled. If every rule is turned off, the parent toggle keeps its previous state.

{% hint style="info" %}
Grant requirements differ by item type. Live grants may require the player online; database-backed schematics, augments, or repair actions may require the player offline. The Console labels the required state.
{% endhint %}
