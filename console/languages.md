# Languages and Translation Corrections

The Console includes 54 languages, including English. Translations ship with project updates; no DeepL account, API key, or subscription is needed to use them.

## Choose a Language

Select the **Console Language** icon in the header, beside **Join Discord**. Search by language name or choose from the list. The selection is saved for that browser, so another administrator or device can use a different language.

Right-to-left languages also change the interface direction. Player names, identifiers, technical values, and other live game data are preserved rather than translated into unrelated text. If a phrase is unavailable, English can appear as a fallback.

## Suggest a Correction

From your installed Console:

1. Open the language picker and choose **Suggest a Translation Fix**.
2. Select the language and search for the current translation or English phrase.
3. Select the phrase, review both versions, and enter **Your Correction**.
4. Preserve any placeholders, such as `{count0}` or `%s`.
5. Optionally enter a name for credits, then select **Submit Correction**.
6. Keep the displayed **Reference** when discussing your suggestion with the project team.

You use your existing Console session; a GitHub account is not required. The submission sends the selected phrase, proposed correction, language, and optional credit name for review. Do not include passwords, tokens, or private player information.

## Review and Delivery

Suggestions are reviewed through the project's website moderation tools. Reviewers can use the reference and phrase context to decide whether the correction fits. Accepted corrections can be collected into a prepared translation update for the project; prepared updates have their own paginated history.

Acceptance does not immediately rewrite every user's Console. Reviewed corrections reach installations through a later project update. Update the Console from **Updates** when the containing release is available, then reopen the language picker if needed.

The language picker does not require a provider key, manual source synchronization, or peer-language sharing. Scanning source phrases is not the same as translating them.
