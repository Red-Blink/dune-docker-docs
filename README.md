# Dune Docker Documentation

Dune Docker Console is a complete self-hosting and administration platform for **Dune: Awakening** dedicated servers. It combines guided installation, Docker-based game services, a browser Console, player and world administration, safe backups, updates, a public server directory, a private Player Portal, and permissioned Community Addons.

{% hint style="warning" %}
Dune Docker is an unofficial community project. It is not affiliated with, endorsed by, sponsored by, or supported by Funcom. Dedicated-server behavior can change when Funcom updates the game.
{% endhint %}

## What You Can Manage

The Console covers the full operating lifecycle: server health and logs, game and Console updates, automatic and manual backups, map modes and Sietches, one to three Deep Desert instances, player progression and recovery tools, bases and land claims, vehicles, guilds, Landsraad information, CHOAM market tools, live-map activity, broadcasts, scheduled messages, Care Packages, settings, optional public listings, and Community Addons.
