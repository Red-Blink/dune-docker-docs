# Enable and Spawn Regis Tanks

Regis Tanks are an optional experimental feature, **disabled by default**. They use a build-specific server patch and do not require a client patch. Only supported game builds can enable them.

## Enable Tanks

1. Make a backup and warn players that Hagga Sietches will restart.
2. Open **Settings → Experimental Features → Regis Tanks**.
3. Choose **Enable**, confirm, and wait for the operation to finish.
4. Wait for Hagga to become ready before joining.

The patch applies to Hagga Sietches, not Smugglers Run or every map. A green enabled card describes the feature setting; also check the operation result and map readiness.

## Spawn a Tank

Open **Players**, select the online player, then **Admin → Spawn Vehicle → Regis Tank**. Choose a Tier 6 preset: Booster or Inventory, paired with Dart, Rocket, or Flame.

Stand still on clear, safe ground while spawning so the Console can obtain a fresh position. Avoid quicksand, buildings, cliff edges, and crowded vehicle areas. Wait for the existing request to finish instead of submitting repeated spawns.

## Disable Tanks or Update the Game

Disabling restores the original game image and restarts affected Hagga Sietches. Treat existing tanks as disposable: the disable confirmation warns that tanks will be deleted from Hagga. Do not leave important cargo in them.

Game-server updates are blocked while tanks are enabled. Disable the feature first, complete the game update, and re-enable only when the Console supports the new build. A previously working patch is not automatically safe for a new Funcom build.

## Known Limitations

The Dart weapon can show pink firing effects and lack firing audio on an unmodified client. Tank-related HUD/module warnings and reports of client crashes or unreliable joins remain relevant limitations; successful spawning does not establish that every client effect is working.

If enabling tanks causes a client to crash or fail to join, capture the client log and relevant server logs, disable the feature during a maintenance window, and compare the result. Do not repeatedly delete an active login queue to work around a crash. Include the Console version and game build when reporting it.
