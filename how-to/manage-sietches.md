# Rename or Add Sietches

Your public server title and each Hagga Sietch's name are separate settings. Changing the public title does not rename every Sietch.

## Rename a Hagga Sietch

Open **Maps**, choose **Edit** on Hagga Basin or the additional Sietch, and change **Name**. Save using **Save Map Settings** or **Save Sietch Settings**, respectively.

The affected running Sietch restarts. Wait for it to become ready and refresh the in-game list before checking the new name. Keep names readable; the editor rejects unsupported characters, and Funcom can also reject display names during registration.

## Add Another Sietch

Edit the primary **Hagga Basin** entry, increase **Active Sietches**, and save. Let the operation finish before editing another setting. Additional Sietches appear as separate rows and can have their own names and passwords.

Each running Sietch consumes additional memory and a game port. Check [Memory and Map Capacity](../operations/memory-and-capacity.md) and your [port ranges](change-game-ports.md) first.

## Reduce the Number of Active Sietches

Move players out of the Sietch being disabled, lower **Active Sietches**, and save during a maintenance window. Reducing the count can also restart the Director and primary Hagga so the removed entry is withdrawn from the in-game listing. It is not the same operation as changing one Sietch's password.

Wait for completion, refresh the in-game list, and confirm only the intended Sietches remain joinable. Do not use database deletion to remove a stale listing.

For map modes, Deep Desert instances, and dynamic destinations, see [Maps, Sietches, and Deep Desert](../console/maps-and-sietches.md).
