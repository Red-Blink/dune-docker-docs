# Set a Sietch Password

A Sietch password controls entry into that Hagga Sietch in the game. It is different from the password used to sign into the browser Console.

## Add or Change the Password

1. Open **Maps**.
2. Find **Hagga Basin** and choose **Edit**. For an additional Sietch, use **Edit** on that Sietch's own row.
3. Enter the new **Password**.
4. Select **Save Map Settings** for the primary map, or **Save Sietch Settings** for an additional Sietch.
5. Wait for the operation to finish and the Sietch to become ready. Refresh the in-game server list, then join using the new password.

Saving a name or password restarts the affected running Hagga Sietch. Warn players first. Other Sietches do not need a restart just because this Sietch's password changed.

An existing saved password is masked. Leaving it untouched preserves it. Do not share screenshots or logs containing an unmasked password.

## Remove the Password

Edit the same Sietch, clear the Password field completely, and save. Once the Sietch is ready and the in-game list has refreshed, test joining without a password.

## Check That It Worked

- The Console should show whether the Sietch has a password set.
- After the restart, the in-game listing should show its password protection.
- A wrong password should be rejected; the correct one should let you join.

If the listing shows an old name or password state, refresh it after the Sietch is ready. If the stale information persists, collect the save result and recent Director, Gateway, and affected map logs. Do not repeatedly edit generated files or restart unrelated services to guess at a fix.

Changing **Active Sietches** has different restart effects. See [Manage Sietches](manage-sietches.md). To change the administrator login instead, use **Settings → Login Password** or [Recover the Admin Web Password](../console/recover-admin-password.md).
